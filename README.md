## 🎮 玩法(現行版,三步驟)

| 步驟 | 動作 | 說明 |
|:---:|---|---|
| 1 | **雙手併攏舉高過肩** ✋ | 雙手靠近併攏,舉到肩膀以上,彈弓皮兜自動吸附 |
| 2 | **往下拉弓** ⬇ | 併攏的雙手一口氣往下拉過肩!拉得越低射得越高,可左右微調準星 |
| 3 | **續力 3 秒發射** ⏱️ | 拉住皮兜續力 3 秒,蓄力圈蓄滿瞬間彈丸自動破空射出! |

- 60 秒內擊落越多水果分數越高(青蘋果 20 分 > 水蜜桃 15 分 > 其他 10 分)
- 中途把手拉回肩上或放開雙手 = 取消蓄力(**不會誤射**)
- 被打落的水果 2.5 秒後長回來,可以一直打
- 時間到彈出結算木牌,依分數頒發稱號(👑 傳奇神射手!等),可「再玩一局 🔄」

## 🛠 技術架構

- **Vite + 原生 JavaScript**(無框架)
- **MediaPipe Tasks-Vision**:Pose Landmarker(骨架/肩膀)+ Hand Landmarker(雙手),GPU 優先、CPU 自動降級,模型與 WASM 100% 本地載入
- **Canvas 2D**:全手繪 UI(水果、彈弓、卡通手、教學圖卡、結算木牌)
- **Web Audio API**:音效即時合成,無音檔

```
水果/
├── index.html                   # HTML 遊戲入口
├── package.json                 # 專案配置(dev port 5175)
├── README.md                    # 本文件(說明 + 開發記錄)
├── public/
│   ├── models/                  # 本地 MediaPipe 模型(pose_lite 5.8MB / hand 7.8MB)
│   └── wasm/                    # 本地 WASM 引擎 ×6(免連 CDN)
└── src/
    ├── main.js                  # 主程式控制器、UI 生命週期、主迴圈
    ├── style.css                # 深色科技感 + 童趣響應式樣式
    ├── game/slingshotGame.js    # 遊戲狀態機、手勢判定、蓄力、碰撞、穩定化
    ├── render/gameRenderer.js   # 畫布渲染(樹梢/水果/教學圖卡/小人/結算)
    ├── render/cartoonHands.js   # Q 版向量卡通手(握拳 ✊ / 張掌 🖐️)

        └── vision.js            # MediaPipe 雙模型封裝(GPU→CPU 降級)
```

## ⚙️ 判定邏輯(狀態機)

```
IDLE ──(併攏 + 舉高過肩)──→ READY(吸附皮兜)
READY ──(併攏 + 拉到肩下45px,連續4幀)──→ PULLING(開始蓄力)
PULLING ──(續力滿3秒)──→ 自動發射 → IDLE
PULLING ──(手拉回肩上25px內 / 雙手分開超過0.25秒)──→ 取消,不發射
```

### 可調參數(都在 `src/game/slingshotGame.js`)

| 參數 | 預設值 | 說明 |
|---|---|---|
| `CHARGE_REQUIRED_MS` | 3000 | 續力發射秒數 |
| 併攏門檻 | `min(180, width*0.25)` | 雙手距離小於此值 = 併攏 |
| 過肩容差 | +15px | 手中點低於肩線多少內算「過肩」 |
| 進入拉弓 / 取消拉弓 | 肩下 45px / 25px | 遲滯帶,防臨界抖動 |
| 平滑係數 | 手 0.45 / 肩 0.3 | 指數平滑,越小越穩、越大越靈敏 |
| 防抖幀數 | 併攏 3 幀 / 拉弓 4 幀 | 連續命中才切換狀態 |
| 手遺失寬限 | 600ms(拉弓中) | 短暫抓不到手不會中斷蓄力 |
| 手分開寬限 | 250ms | 微分開不會誤判放手 |

## 📜 開發與修改記錄 — 第一輪 v1

> 本章節記錄專案從 `bone-next` 初始狀態到第一版彈弓遊戲的開發歷程。
> 其中「玩法判定」部分已被第二輪改版取代,保留作為歷史記錄。

### 1. 專案背景與初始狀態

初始狀態體檢(`C:\aiii\bone-next`):

- **原專案性質**:單一檔案 `src/main.js`(256 行)的簡易碰觸計次網頁,依賴 `@mediapipe/tasks-vision` 與 `vite`。
- **原存痛點**:
  1. **職責混雜**:UI DOM、Webcam 管理、AI 視覺推論、Canvas 繪圖全擠在單一檔案,擴充困難。
  2. **模型載入依賴外網**:WASM 引擎指向外部 jsdelivr CDN,遇到網路延遲或阻擋容易卡死。
  3. **玩法單一**:僅一個固定在畫面上方中央的圓形目標,無音效、無倒數、無豐富視覺回饋。

### 2. 核心玩法設計變革(v1 設計)

經多輪討論確定「體感彈弓射水果(1 分鐘限時挑戰)」完整規則:

1. **體感手勢互動(v1,已被第二輪取代)**:
   - 抓取準備:雙手在胸前靠近並攏,皮兜自動吸附。
   - 向下拉弓:拉得越長射得越高;左右微調控制偏角與瞄準線。
   - 放手射擊:「張開手掌 🖐️」或「雙手分開」即發射。
2. **畫面視覺層次**:
   - 動作校準教學木牌(3 步驟引導,完成自動收起)。
   - 左下角立式木牌:⏱️ 倒數、⭐ 得分、🍎 擊落數。
   - 頂部滿版樹梢 + 7 顆彩色水果(紅蘋果、甜橙、水蜜桃、黃檸檬、青蘋果),每顆帶發光光環。
   - Q 版卡通白手套:皮兜被肉嘟嘟白拳 ✊ 握住,放手切換張掌 🖐️。
3. **時間結算**:60 秒結束彈出結算木牌 + 稱號評級(如 👑 傳奇神射手!)+ 「再玩一局 🔄」。

### 3. 核心模組實作(v1)

- **遊戲狀態機**(`slingshotGame.js`):`CALIBRATION → PLAYING → FINISHED` 三階段;手部幾何判定融合 HandLandmarker(指尖/掌心)與 PoseLandmarker(手腕備用),避免單一模型掉點;下拉距離線性映射射擊高度(拉得越低目標越靠近樹頂);水平偏移反向牽引手感,即時聯動發光拋物虛線;水果碰撞寬容圈(Hitbox)+ 重力掉落( vy += 0.45)與隨機自轉;掉出螢幕後 2.5 秒原位重生。
- **向量卡通手**(`cartoonHands.js`):純 Canvas 貝茲曲線,無須圖檔 — `drawFist()` 肉嘟嘟白拳(指節腮紅)、`drawOpenPalm()` 五指張掌(掌心肉墊)。
- **場景渲染**(`gameRenderer.js`):頂部多層次樹冠與枝幹、發光水果光環(瞄準時亮金黃脈衝)、左下立體木牌、教學/結算面板。
- **Web Audio 音效**(`audio.js`):零延遲合成 — `playStretch(progress)` 隨拉力變頻皮筋聲、`playShoot()` 破空滑音、`playFruitHit()` 雙頻爆裂「啵碰」、`playFruitRespawn()` 重生彈性音、`playTick()`/`playTimeUp()` 最後 10 秒滴答與四音和弦結算鈴。

### 4. 關鍵問題修復:載入模型卡住排查

首次測試卡在「載入模型中…」,排查修復四項:

| 問題點 | 根本原因 | 修復方案 |
| :--- | :--- | :--- |
| **WASM 載入超時/阻擋** | 原指向外部 CDN(`cdn.jsdelivr.net`),本地網路易逾時。 | 6 個 WASM 核心檔完整拷貝至本地 `public/wasm`,`vision.js` 改 100% 本地載入。 |
| **GPU 環境相容性** | 部分顯卡 WebGL/GPU Delegate 初始化丟失 context。 | `vision.js` 新增 **GPU 失敗自動降級 CPU**。 |
| **相機 Promise 掛起** | `loadedmetadata` 可能晚於監聽器或根本不觸發,`await` 永久等待。 | `camera.js` 加入 `readyState >= 1` 即時檢查、3 秒超時保護、解析度降級重試。 |
| **介面啟動指引** | 啟動按鈕在畫面下方易被忽略。 | 畫面中央加入醒目黃色按鈕「立即啟動 Webcam 🎥」+ 即時回報載入步驟(WASM → 人體模型 → 手勢模型 → 攝影機)。 |

## 📜 開發與修改記錄 — 第二輪:判定改版與長輩友善 UI(現行)

> 2026-10-06 完成並上線。目標:發射判定改為長輩容易成功的動作序列,並簡化視覺。

### 1. 發射判定全面改版

- **新流程**:雙手併攏**舉高過肩**(吸附)→ 維持併攏**往下拉過肩**(進入蓄力)→ **續力 3 秒自動發射**。
- **移除舊觸發**:張手發射、雙手分開發射、手離開畫面誤射 — 全部移除。
- 新增肩膀偵測(pose landmarks 11/12):取得肩線高度與肩寬作為動作基準,抓不到肩時有畫面高度 30% fallback。
- 蓄力以真實時間差累計(單幀上限 100ms,防切頁回來暴衝);發射後自動回 IDLE,需重新舉手才能再抓,防連發。
- 教學三步驟跟著新流程:吸附 → 下拉 → 續力 3 秒(教學與正式遊戲共用同一份蓄力程式)。

### 2. 關鍵 Bug 修復

| Bug | 根本原因 | 修復 |
| :--- | :--- | :--- |
| **正式遊戲無法射擊**(骨架有抓到但沒反應) | READY(要求肩上)與 PULLING(要求肩下)條件互相矛盾,永遠不可能同時成立,狀態卡死在 IDLE;教學因直接強制設狀態而沒察覺 | 抓住之後下拉不再要求留在肩上,只要求維持併攏 |
| **教學蓄力變 1.5 秒** | 教學分支與 PULLING 分支各加算一次 dt | 蓄力統一由 PULLING 分支處理,教學只負責狀態 |

### 3. 穩定性強化(五道機制)

實測「難抓到動作」後加裝:

1. **指數平滑**:手部中點/距離係數 0.45、肩線 0.3,過濾每幀座標抖動。
2. **肩線記憶 2 秒**:pose 短暫抓不到肩不會跌回 fallback 亂跳。
3. **防抖計數**:併攏連續 3 幀、進入拉弓連續 4 幀才切換狀態。
4. **寬限時制**:拉弓中手遺失 <0.6s 沿用最後位置(蓄力不歸零);手微分開 <0.25s 不中斷。
5. **Fallback 加強**:單手可玩(視為併攏);完全沒手時改用 pose 手腕(visibility 門檻 0.35→0.25)。

### 4. 長輩友善 UI

- **水果極簡化**:移除發光光環、彩色底圓、漸層陰影,只留放大 emoji(字級 r×2.1)+ 細枝梗;水果本體加大(半徑上限 30→36)。
- 瞄準提示改為整顆**放大脈動**(不再靠發光框)。
- **三欄圖卡式教學木牌**:數字徽章、當前步驟高亮黃底、完成打勾;純 canvas 繪製的**示意小人**(舉手過肩 / 併攏下拉 / 續力碼錶)+ 虛線箭頭,卡片間有銜接箭頭。
- 小人插圖經 4 輪截圖迭代:手臂雙層描邊(深棕外框+綠色內芯)、舉手避開頭部(沿頭側上舉)、下拉手位於胸前。
- 蓄力視覺:準星外圈蓄力進度環(橘→綠)+ 倒數秒數;教學牌內進度條「續力中…剩 N 秒發射」。
- 文案全面同步(教學牌、底部提示卡、副標)。
